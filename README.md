## Description

TheMatrix est mon neuvieme projet de la picine python de 42. Le but est de toujours ce famialiariser et de voir les base du python avec des exercices simples.

## Detail

| Exercices | Role |
|-----------|------|
| ex0 | Le but de cet exercice est de creer et comprendre un environemment. |
| ex1 | Le but de cet exercice est de savoir utiliser un requirements et different module(pandas, numpy, matplotlib). |
| ex2 | Le but de cet exercice est de comprendre le .env et l'importance des donnees sensible avec les differents mode production et development. |
